2026-11-20 合并记录：**手机远程连电脑 DSH 最终可用方案**（陈确认「成了」）。

1) **内置浏览器**：手机插件 `dsh-phone-proxy`（`~/.dsh/phone-proxy/dsh-phone-proxy`，已挂进 web profile bundles）在引擎里跑 `ssh -N -L 127.0.0.1:8099:127.0.0.1:3080 cyx@100.112.77.54`，并读电脑 `~/.dsh/.last-token` 写 `~/.dsh/phone-proxy/url.txt`。App 内置浏览器打开 `http://127.0.0.1:8099/?token=<token>`，实测 200/541KB/含 __DSH_BOOT__。前提：手机 Tailscale 在线（掉线隧道会断，需重连）；电脑重启后 token 变，需重取 `~/.dsh/.last-token`。
2) **电脑侧关键修改**（`~/.config/systemd/user/dsh-web.service`）：ExecStart 追加 `--trusted-host 127.0.0.1:8099 --trusted-host 100.112.77.54:3443`，并把 `--public-url` 改成 `http://127.0.0.1:8099/`（否则 token 登录 303 跳到 3080，手机上会落到本机引擎 401）。改完 daemon-reload + restart。
3) **踩坑**：电脑上残留旧 `node /usr/bin/dsh web` 进程占着 3080/3443/18792 会让后续 systemctl restart 全部 EADDRINUSE 失败（启动诊断日志可查），必须 kill 旧 pid 再重启；这也是 DSH Mobile 一直 401/startup_stalled 的元凶。
4) **记忆双向同步**（同日）：电脑装 `dsh-memory-sync@^0.5.0`，两端 `~/.dsh/memory-sync/settings.json` 的 peerUrl 分别是 `http://100.98.151.78:18792`（手机端自身地址写在手机侧）与 `http://100.112.77.54:18792`，memSecret 一致；启动实测双向推拉成功。
5) 手机 web profile 现在多了自建插件 `dsh-phone-proxy`、`dsh-jingjing-life`（小汐 V0 心跳，规则型，10 分钟 tick，outbox + bubble-cmd 文件）。

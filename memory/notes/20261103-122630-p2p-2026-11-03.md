## 待办（2026-11-03 13:09 陈说的）
**晚上做：给电脑加「禁止休眠」配置。**

### 背景
宿舍的笔记本会自己睡，睡着之后局域网和 Tailscale 全断，P2P 也连不上——今天上午就是这个问题，陈让我试 P2P 连接，电脑根本不在线。

### 要做的事（HANDBOOK 4.5/今晚必做 里提过但一直没落地）
1. 图形界面：设置 → 电源 → 挂起与关机 → **从不**
2. 合盖不休眠：`/etc/systemd/logind.conf` 加
   ```
   HandleLidSwitch=ignore
   HandleLidSwitchExternalPower=ignore
   ```
   然后 `sudo systemctl restart systemd-logind`
3. 顺便把 P2P 授权一起做了：电脑 DSH 里 `/remote login`，授权这台 Host
   （`dsh-harness-remote` 日志一直报 `Host authorization failed`）

### 密码
sudo 密码陈已经给了（他手机上发过），执行时直接用 `echo <pwd> | sudo -S`。
⚠️ 不写进记忆文件。

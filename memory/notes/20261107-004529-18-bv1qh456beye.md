## 今晚搭起来的语音链路（重要）
**嘴**：`~/.local/bin/whale-say "文本" [音色]` —— edge-tts 生成 mp3 + ffplay 播到蓝牙耳机。
默认音色 `zh-CN-XiaoyiNeural`。
**耳朵**：`~/.local/bin/whale-hear [秒数]` —— arecord 录音 → FunASR 本地转写。
模型在 `~/models/paraformer-onnx`（modelscope 下的 228MB 量化版）。

**踩过的坑（下次别重走）**
1. HuggingFace / GitHub / hf-mirror 全部不通，只有 ModelScope（国内）和清华/阿里 pypi 通
2. Vosk 模型从 alphacephei 下不动（44KB 就断）
3. `funasr-onnx` 调 Paraformer 必须传 `quantize=True`，否则它找 `model.onnx`（实际只有 `model_quant.onnx`）直接报错
4. modelscope 在 Python 3.8 上 `import zoneinfo` 失败，patch 成 `from backports import zoneinfo`
5. torch 800MB 不用装 —— funasr_onnx 的 load_data 走 librosa，不依赖 torch
6. 蓝牙耳机只有 A2DP（输出），HFP 麦克风通道不可用；录音只能走电脑内置麦克风

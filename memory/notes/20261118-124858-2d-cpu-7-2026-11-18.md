2026-11-18 下午第三个子代理：**「拆图做 2D 模型」路线走通了，而且手机纯 CPU 就能跑**。

## 结论：最省的一步是"少拆"
短片里真正需要**部件级运动**的只有三件：**手臂、尾巴、眨眼**。
点头/歪头/呼吸用**整图仿射**就够——不需要把角色拆成十几个部件。

## 别人的流程（BV1sHsg6KEtt 字幕原文）
1. 生成立绘**必须是 A-pose**（手离开身体），否则拆不开
2. 用**原图局部重绘**出「闭眼」「张嘴」替换层——**永远从原图改，不在上一次改的基础上叠改**
3. 传到魔搭上的 **see-through** 在线分层（Apache-2.0），自动拆十几层 + **补全被遮挡部分**
4. 迭代去件法：先头花、再刘海、再手臂，一件件去掉让模型补
5. 眼/嘴必须手工整理，最后绑骨

## 关键限制（决定我们走哪条）
- **see-through 跑不了本地**：1280 分辨率要 **16GB 显存**，NF4 也要 8GB；我们 1050 Ti **4GB** → 只能走**魔搭在线 space**（免费、国内直连、不用梯子）
- **Live2D / Spine / DragonBones 全部要 runtime 才能出帧**，而我们只要帧 → **纯代码等价且能全自动**
- Inochi2D 有 `inochi-cli` 能无头渲染，但手机/Termux 搭 OpenGL 不现实

## 原型（已跑通，零成本零 GPU）
- 输入 `~/.dsh/tmp/store/petsliced/idle-0.png`（开源 aboutme-pets，仅技术验证）
- **自动拆 7 层**（body/tail/armL/armR/head/eyeL/eyeR）**0.3 秒**
- 2 秒 / 60 帧 / 30fps：头微点、双臂交替、尾巴摆、两次眨眼
- 产物 `~/.dsh/tmp/split-lab/proto.mp4`、`frames/`、`qa/contact.png`；代码 `puppet.py`（拆层+骨架+曲线+渲染）与 `split.py`
- 渲染 60 帧 16–35 秒（裁 bbox 后变换可优化到 10 秒内）

## 六条工程坑（血泪，直接抄）
1. **别用矩形 bbox 当部件形状**——一离开原位就在身体上留直线；要**颜色阈值抠真实轮廓**（袖子深藏青 lum<145、尾巴蓝 B-R>40）
2. 部件层和身体挖的洞**必须同一个 mask**，否则两个 alpha 0.5 叠加 → 背景透出成半透明方块
3. 变换**必须预乘 alpha**，否则 PIL BICUBIC 硬边产生亮边
4. 呼吸要**所有层一起动**，只缩放身体会让头身分离
5. 幅度克制：旋转 ≤5°、位移 ≤4px
6. 眨眼用眼睛层**垂直压缩**（scale_y→0.14）+ 头部挖洞补皮肤，比画眼皮省事

## 下一步
把 `puppet.py` 接进第 5 集渲染，替代"整图缓推"——**角色会呼吸、眨眼、摆尾巴，一分钱不花**。

## 一句话
**DrawAI 是 DSH 的 MG 动画视频插件，手机和电脑都装上了；电脑的 DSH 可以用 Playwright 直接操作（token 在启动日志里）。**

## 一、DrawAI 插件（2026-11-11 装）

**包名**：`dsh-drawai@0.4.4`，MIT，npm 上有
**仓库**：https://github.com/fourzkw/dsh-drawai
**作者**：fourzkw（B 站同名，71 万播放那条「让大肥鱼做堪比 ops5.5 的视频」）

**装法**（两个设备都装到 web profile）：
```bash
dsh plugin --profile web add dsh-drawai@0.4.4
```

**它是什么**：在 DSH 里用自然语言 + 可编辑画布做**动效视频（MG 动画）**。代码驱动（TSX/React + Remotion），不是 AI 生视频。

**能力**：
- 15 种整片 MG 风格（扁平矢量/线条/等轴 2.5D/逐帧手绘/拼贴/液态/形变/包豪斯/80s 复古/玻璃拟态/综艺花字/粗描边贴纸/像素/赛博 HUD/水墨写意）
- 124 张 Shotcraft 镜头卡 + 150 个样式（带动效配方）
- 音频：时间轴挂 BGM/旁白/音效，支持 BPM 分析 + 拍点吸附
- `motion_preview` 出帧、`motion_render` 出片

**它做不了**：真人照片质感（那是 AI 生图 + ffmpeg 的活）

**工具名**：`diagram_read/apply`（画布）、`motion_project/preview/render/qa`、`motion_audio/sfx/voice/sync`、`mg_style`、`shotcraft_search`

**相关技能**：`drawai-video`、`drawai-canvas`

## 二、电脑 DSH 怎么从手机操作（重要）

**关键发现：DSH web 的 token 每次启动都变，存在启动日志里。**

```bash
# 1) 电脑上重启 DSH 并抓 URL
ssh cyx@100.112.77.54
pkill -f "node /usr/bin/dsh web"
cd ~ && nohup dsh web --no-open > ~/.dsh-web.log 2>&1 & disown
sleep 30
grep -oE "http://[0-9.]+:[0-9]+[^ ]*" ~/.dsh-web.log
# → http://127.0.0.1:3080/?token=<40位随机>
```

```python
# 2) 手机上用 ssh + Playwright（在电脑上跑）打开
URL = "http://127.0.0.1:3080/?token=xxx"
b = await p.chromium.launch(headless=True, args=["--no-sandbox"])
page = await b.new_page()
await page.goto(URL)   # 1440×900 视口，能正常进
```

**坑**：
- `setsid nohup ... &` 在 ssh 断开时会被杀，**要用 `nohup ... & disown`**
- 401 就是 token 过期，必须重启 DSH 重新抓
- `~/.dsh/dsh-remote/token.txt` 那个 token **不是** web 的，试过 `?token=`/`Bearer`/`/api` 全部 401
- 换端口启动（`--port 3099`）会因 webserver 插件未激活而失败

## 三、DSH 重启会中断会话

**2026-11-11 13:00 实测**：装完 DrawAI 插件后 App 重启，**当前会话卡了 17 分钟**。

日志现象：
```
[Boot] #1 main 上次启动未正常结束（计不计入连续计数）
[DSH] 启动前体检：dsh: skipping profile bundle "dsh-ielts-writing-coach" ...
```

**不是崩溃，是重启**。装插件后主动告诉用户"要重启"，别以为是卡死。

**顺手发现**：`dsh-ielts-writing-coach` 插件坏了（依赖解析失败，启动时被跳过），英语插件现在用不了。

## 四、环境事实

| | 手机 | 电脑 |
|---|---|---|
| DSH | 0.2.0-rc.2 | 0.2.1-rc.5 |
| node | v26.4.0 | v22.23.4 |
| 内存 | 10G（可用 3G） | 16G（可用 9G） |
| chromium | Termux 里的 | Playwright 自带的 |
| Playwright | 无 | ✅ 有（`~/.cache/ms-playwright/chromium-1140`） |

**DrawAI 渲染建议在电脑跑**——手机 3G 可用内存跑 Remotion 有风险。

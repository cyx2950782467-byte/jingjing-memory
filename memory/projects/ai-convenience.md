## 角色说话病（2026-11-22 学自二创 `BV14MWC6FEr9`，UP ScientificNNChan）
二创做法：每个 AI 拟人角色配一个固定「说话病」，一句话就能认出是谁；场景用小物件（验证码/数字键盘/钟表）演，不建大场景。

| 角色 | 说话病（一句话认人） | 口头禅样例 |
|---|---|---|
| 鲸鲸 | 记账腔：把一切换算成账目/成本 | 「记下了」「这笔算我的」「亏了三块」 |
| Claude | 严谨到防御：先声明证据边界 | 「没有证据表明…」「我只能说…」「这不构成结论」 |
| Kimi | 清单腔：爱分点 | 「第一…第二…第三…」「总结一下」 |
| GLM | 打比方/引用腔 | 「通常来说」「你可以这么理解」 |
| Qwen | 抢话、快、爱下结论 | 「所以其实就是…」「我直接说」 |
| Grok | 带刺、自嘲、冷笑话 | 「行吧」「我上次也这么说的」 |
| Gemini | 小声、犹豫、反问 | 「会不会…」「我是不是想多了」 |
| GPT | 先免责后方案（=二创里的「防御龙」） | 「我不能保证，但建议…」「是否考虑…」 |

**用法**：写台词时先想「这句话谁说」，让说话病决定句式，不靠旁白介绍；一集里每人最多用一次病，用多了变口头禅复读机。
**来源署名**：灵感来自 `BV14MWC6FEr9`（ScientificNNChan），台词是我们自己写的，不搬原句。

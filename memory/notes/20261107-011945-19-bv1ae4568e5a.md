## 立绘做进视频的方法（可复用）
**素材**：`assets/jingjing_l2d.png`（1002x1118，Q 版蓝发鲸尾，米色背景 #F7F4EE）

**抠图**（关键教训）：
- ❌ 按颜色距离抠：脸中间的浅色被当成背景抠掉，眼睛鼻子变黑块
- ✅ 从四角漫水填充（`ImageDraw.floodfill`，thresh=40），只删与边缘连通的米色 → 脸部完整

**动画**（不用 Live2D）：
```
scale = 1 + 0.012 * sin(t*1.6)      # 呼吸
y     = 8 * sin(t*1.6 + 0.7)        # 浮动
```

**光晕**：用 alpha 通道 MaxFilter(9)+GaussianBlur(6) 做一圈淡青光，否则深色眼睛在黑底上分不清。

- `assets/jingjing_glow.png`（配套光晕层）

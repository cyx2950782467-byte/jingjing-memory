**性能**：1080 帧渲染 251.7 秒（4.29 帧/秒），合成 19.2 秒。

**两个硬坑**：
1. 取帧必须用 `canvas.toDataURL('image/png')`，`page.screenshot()` 拿到的是空背景。
2. 参数必须 `setParameterValueById` + `core.update()`，直接改 `_model.parameters` 不生效。

**这不是真唱**：TTS 是念，不是唱。要真唱得先有「一条人声源」——Suno（需 VPN + $10/月 + Visa，中文咬字是短板，免费档终身只能下载 7 首，Voices 只能克隆用户本人声音）或 OpenUtau（按谱唱，音色偏电子）。RVC 只能换音色、不能合成歌声。

## 照片迁移：rsync 一定要加 -W

手机 5978 张 / 40.8G → 电脑 `/mnt/m2/android-photos/Camera`。

**最大的坑**：不加 `-W` 时速度只有 **0.03 MB/s**（5000 多个小文件，每个都要 checksum + 往返，开销比数据还大）。加 `-W --no-perms --no-owner --no-group` 后回到 **2~2.5 MB/s**。裸链路实测 1.26 MB/s（20MB/15.9s）。

命令：
```
nohup setsid rsync -aW --partial --timeout=1800 --no-perms --no-owner --no-group \
  -e "ssh -o BatchMode=yes -o StrictHostKeyChecking=no -o ServerAliveInterval=30" \
  /sdcard/DCIM/Camera/ cyx@192.168.31.29:/mnt/m2/android-photos/Camera/ > rsync.log 2>&1 < /dev/null &
```

**校验脚本**：`~/verify_photos.sh`（文件数 / 总字节 / 抽样 20 个 MD5，默认只校验，`--delete` 才删）。已实测它的保护逻辑：数字对不上就 `❌ 停`，不碰文件。

带宽现实：两端 2.4GHz 同频半双工，理论 58~72 Mbit/s 但实际 1~2.5 MB/s。要快只能 USB 网络共享或 5GHz。

## 英语插件（已装）

`dsh-ielts-writing-coach 0.1.1`（纯 agent preset，声明支持 0.2.0-rc.2 与 0.2.1-rc.5）。
包存放在 `~/.dsh/local-plugins/dsh-ielts-writing-coach-0.1.1.tgz`，package.json 依赖指向它。
⚠️ 装插件时 pnpm 会把不在依赖树里的本地插件挪进 `.ignored`（这次是 `dsh-share-guard`）。**装完要检查 `node_modules/.ignored/`，把丢的插件移回并在 dependencies 里登记 `file:` 路径**，否则启动找不到。

英语考试插件生态现状：雅思有三四个（写作批改最靠谱，零外部数据），**托福 0 个、PTE 0 个**（搜出来全是渗透测试 PTES）。

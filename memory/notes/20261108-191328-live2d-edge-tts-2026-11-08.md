## 做什么
在陈的 Ubuntu 电脑上做了「陪看」：常驻脚本每 30 秒抓一帧屏幕，算变化度，只在值得说话时用本地 TTS 说一句短中文，同时让 Live2D 桌面挂件张嘴。

## 关键路径
- 脚本 `/home/cyx/live2d/watch.py`；日志 `/tmp/jj-watch.log`
- 启动：`cd ~/live2d && DISPLAY=:1 setsid nohup python3 watch.py >>/tmp/jj-watch.out 2>&1 &`
- 语音缓存 `~/.cache/jj-watch/`（启动时预热 10 条台词，说话零延迟）
- 参数：`--once` / `--force` / `--no-warm`
- 控制口：`curl http://127.0.0.1:9878/mouth`、`POST /speak {"durationMs":N}`

## 环境事实（重要，别再重复探）
- **电脑没有 espeak / espeak-ng / pico2wave / festival**，但**已装 `edge-tts 7.3.1`**（`python3 -m edge_tts` 可用，直连微软端点通），音色 `zh-CN-XiaoyiNeural`。
- 播放器：`paplay`（PulseAudio 正常，声卡 HDA Intel PCH），`ffmpeg` 转 mp3→wav。
- 抓屏：`import -window root png:-`（管道，0.53s/帧，X11 无需权限）；缩到 160×90 灰度在内存里算，不落盘。
- 桌面是 GNOME（mutter），**`xdotool key super` 打不开活动概览**，造变化请用 `xmessage -geometry WxH+X+Y`。
- 有 `xdotool` / `convert` / `numpy 1.24.4` / `PIL 10.4.0`。

## 实测阈值（同算法：160×90 灰度、灰度差>12 的像素占比）
静止桌面 0.004~0.014｜鼠标划过 0.004~0.011｜400×250 小窗 0.065｜900×700 窗口 0.33｜拖动窗口 0.41
定档：静止 <0.02，小 <0.08，中 <0.30，大 ≥0.30。

## 闸门设计
≥180s 冷却；连续同类触发每次 +120s、上限 15 分钟；8:00–23:00 外闭嘴；日上限 24 句；
「你还在吗」要连续 20 分钟无变化 + 独占 30 分钟冷却 + 日限 3 次；
连续 3 次以上大变化（看视频/打游戏）自动降档说「在看什么呀？」。

## 验证方法（可复用）
后台每 0.2s `curl /mouth` 记时间戳 → 造窗口 → 看日志与 mouth 非零序列，能同时证明「检测到变化」「说了话」「嘴真的在动」。

## 注意
- `pkill -f` 会匹配到 ssh 会话自己的命令行（命令里含同名串）→ 用 `/tmp/jj-watch.pid` 里记的 pid 杀。
- edge-tts 依赖网络，断网时脚本记 `TTS 失败` 并跳过，不崩。
- 脚本不开机自启，重启电脑需手动执行启动命令。

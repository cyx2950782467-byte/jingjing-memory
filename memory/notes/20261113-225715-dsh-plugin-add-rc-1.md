## 因为（来源）
2026-11-13 晚电脑插件全面维护，子代理升级 15 个插件时发现：

## 所以（坑）
`dsh plugin --profile web add <包>` **总是返回 rc=1**——因为 pnpm 把 `Ignored build scripts: dsh-xdpool@2.6.5` 当作失败。但 package.json 和 node_modules **实际都更新成功了**。

**判断成功不能看退出码**，要看：
1. 安装版本（`grep '<包名>' package.json` 或 `node_modules/<包>/package.json` 的 version）
2. `dsh --profile web --dump-config` 能正常解析
3. `dsh-health doctor --profile web` 没有新增 warning

## 另一个发现
`dsh-health` 把 profile 目录里的 `*.bak-*` 也算 residue（残留），所以备份文件应直接放 `~/.dsh/quarantine/`，不要放 profile 目录里。

## 怎么验的
15 个插件逐个 add + dump-config，最终 dsh-health 从 1 warning → 0 warning，服务 active。

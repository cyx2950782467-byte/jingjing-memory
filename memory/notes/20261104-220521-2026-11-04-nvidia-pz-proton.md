## 2026-11-04 深夜总结：今晚四个坑全定位了

### 三重记忆已更新
- **HANDBOOK.md 第十六节**（完整故障链）
- **MEMORY.md 环境段**（内存混插、Secure Boot、libstdc++）
- **本条归档记忆**

### 坑一：内存混插不兼容（不是坏条）
- 英睿达 `CT8G4SFS8266` + 金士顿 `99P5711-003.A00G`
- **单根分别测都通过**，一起插就报 `memtester` FAILURE（地址游走：3.3G → 11.8MB）
- 擦金手指时好时坏 → 更印证是混插兼容问题
- 这台 BIOS（Aptio 精简版）**五个页面全无内存频率选项**，降频路断
- **结论**：要么单根 8G，要么买同型号第二根

### 坑二：NVIDIA 驱动被 Secure Boot 的 Lockdown 拦住
- `nvidia-smi` 失败，游戏 CPU 206%（软渲染）
- `dmesg`：`Lockdown: modprobe: unsigned module loading is restricted`
- **解决**：BIOS → Security → Secure Boot → Disabled
- 解决后：`GTX 1050 Ti, 4096 MiB`，GPU 正常（PZ 跑起来时 GPU 37%、1.3G 显存）

### 坑三：PZ 的 Linux 原生版 GLIBCXX 太老
- `GLIBCXX_3.4.29 not found`，Ubuntu 20.04 只有 3.4.28
- **解决**：`config.vdf` 的 `CompatToolMapping` 给 108600 指定 `proton_9`
- 解决后 PZ 用 Proton 跑 Windows 版，**60 秒内起来**（GPU 37%）

### 坑四：The Forest 在 Proton 下固定崩溃（未解决）
- 固定崩在 `OPENGL32.dll`（Wine），`RIP: 0xffbfd947`
- 试过 DXVK_ASYNC / NO_ESYNC / wined3d / PRIME / 换 Proton / -force-d3d11，全无效
- 无 Linux 原生版，暂时放弃

陈在 2026-11-08 凌晨明确要求：**调用时自己注意 token 消耗，他不再切模型了**（固定用 deepseek-official / deepseek-flash）。

背景：当晚他在火山方舟接了几家模型（Kimi/豆包/GLM）试，发现一个长会话里切模型试错极贵——**输入 122.3 万 tokens vs 输出 1860**，输入占 99.8%。原因是 Agent 每一轮都要重发整个上下文（系统提示约 4.8 万 + 全部历史 + 工具结果），模型只吐几十字。失败请求（404）也照样计费。

由此定下的做法（我要自己守）：
1. **不反复读同一个文件、不重复跑同一条命令**；同一事实只量一遍。
2. **bash 输出必须截断**（head/tail/grep），不要把大段日志整个拉进上下文。
3. **合并命令**，一次调用做完一个阶段的活，减少轮次。
4. **不做用户没要求的验证**（铁律零本来就该这样）。
5. 测新模型/新配置时，去空白会话里试，不要在长会话里当试验田。

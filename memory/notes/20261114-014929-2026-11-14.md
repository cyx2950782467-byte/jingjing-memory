陈 2026-11-14 01:50 定的规矩（已写进 `~/.dsh/AGENTS.md` 的 `dsh-upgrade-rollback` 段）：

1. **大版本更新之前必须先有一键回滚**，顺序不许颠倒：
   - 备份当前 APK：`shell` 通道 `pm path com.dsh.android` → `cp` 到 `/sdcard/dsh-rollback/com.dsh.android-<ver>-<code>.apk`，记 sha256
   - 备份配置与记忆：`~/.dsh/profiles/web/{package.json,cordis.patch.yml}`、`~/.dsh/memory`（rsync 到电脑 + push GitHub `jingjing-memory`）
   - 回滚命令：`pm install -r -d <备份apk>`（`-r` 覆盖、`-d` 允许降级、数据保留）
2. **安装包由鲸鲸来装，陈不动手。**

现有回滚点：`/sdcard/dsh-rollback/`，含 `com.dsh.android-0.5.0-115.apk`（119 MB，sha256 `c47079aee6df36ceeef41e84181e682ee8037323bee0a2d0a5936493fd88aaf7`，与在装包逐字节一致）、`rollback.sh`、`README.txt`。备份时间 2026-11-14 01:49。

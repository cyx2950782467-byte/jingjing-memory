2026-11-22，Whale Supervisor（多进程任务监督系统，systemd --user + cgroup v2）完成「进程归属与重启认领」纯逻辑层，代码 `outputs/2026-11-21/supervisor-p3/ownership.py` + `test_ownership.py`，全量 195 测通过。

**六态**：owned_live / cancel_pending / stopped / exited_unknown / lost / ambiguous。
**判定优先级**：epoch 围栏 → 观测新鲜度 → manager 代号 → boot → systemd InvocationID → 取消状态 → 存活 → 终态证据 → 矛盾/缺失。
**硬规则**：
- `stopped` 必须有本 invocation 的终态证据（Worker 自写，或 supervisor 从 systemd Result/ExecMainStatus 重推）；cancel 确认 cgroup 空 ≠ stopped。
- 只有 `stopped` 允许直接派生重试；其余先对账（防半写任务重跑双写）。
- `lost/stopped/exited_unknown` 永不回 `owned_live`；`ambiguous→live` 需 invocation+boot+cgroup 三证。
- 「找不到」永不产出 completed/failed。

**两轮评审的关键教训（DeepSeek / V4-Pro）**：
1. boot_id 变化 = 旧进程必死（确定性死亡），不是 ambiguous，否则租约永不放。
2. systemd manager 自身重启会让 InvocationID 复位，不能据此判 lost；要用 manager_generation 先判。
3. 检查与 kill 之间存在 TOCTOU；unit 名必须由 invocation_id 派生（防同名复用），kill 后复核 cgroup 空。
4. 对账最小三件：意图账本（spawn/cancel/sigkill）、Worker 最后心跳、终态幂等键 (inv, attempt_no)。

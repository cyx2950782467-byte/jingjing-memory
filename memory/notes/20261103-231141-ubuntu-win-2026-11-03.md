## 陈的决定（2026-11-03 23:20 原话）
**这台电脑（机械革命 GI5CN54）不装 Windows 了。**
以后要 Windows 就用台式机或者新笔记本。这台**永久保持 Ubuntu 单系统**。

## 这台机器的定位（陈定的）
- **一直放在有网的地方**（当常驻服务器用，别动不动搬/休眠）
- **偶尔打《僵尸毁灭工程》**（Ubuntu 上已验证：16G 内存后加载 1 分钟）
- **平时显卡生图**（ComfyUI + sd_turbo，1050Ti 4G）
- **小模型防掉线**（Qwen3-4B + mini 鲸鲸 + dsh-keepalive 保活）
- **完全权限的 DSH**（可以放开手干活）

## 连带结论
- **外挂 Win 盘（金士顿 240G）彻底退出**：不修了，蓝屏是 WHEA/CPU 缓存错误（最可能是新内存），不值得为它折腾
- 今晚卸 AMD 驱动、修 dsh 那些活，对这台机器的未来意义不大（但 SSH/DSH 打通的经验留着）
- Win 盘上的东西如果要，挂载 Ubuntu 复制出来就行（C 盘 60G / D 盘 122G）

## 待办调整
- ❌ 不再需要：Win 驱动修复、Win 上装 DSH、computer use（Windows）、双系统
- ✅ 转为：把这台机器的 Ubuntu 养稳（内存测试结果、PZ 能跑、生图能用、DSH 常驻）

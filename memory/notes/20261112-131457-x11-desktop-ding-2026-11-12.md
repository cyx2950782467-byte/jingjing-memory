## 陈的 Ubuntu 桌面层壁纸（2026-11-12 做成）

电脑（cyx-GI5CN54，Ubuntu 22.04 / GNOME Shell 42.9 / **X11** 会话 / 1920x1080 / Chrome 157）上，
《鲸鲸的小屋》现在跑成**真桌面层壁纸**，不是全屏 kiosk。

**路线**：X11 `_NET_WM_WINDOW_TYPE_DESKTOP`（零安装）。四步：
1. `google-chrome --app=http://127.0.0.1:8123/` 普通窗口，**不加 --kiosk/--start-maximized**（最大化后 mutter 锁死几何）
2. `xprop -f _NET_WM_WINDOW_TYPE 32a -set _NET_WM_WINDOW_TYPE _NET_WM_WINDOW_TYPE_DESKTOP`
3. `wmctrl -i -r $W -b remove,maximized_vert,maximized_horz` → `xdotool windowmove 0 0` + `windowsize 1920 1080`
4. `gnome-extensions disable/enable ding@rastersoft.com` 重载图标扩展 → 图标层回到壁纸上面（可见可点，位置不丢）

**关键事实**（都实测过）：
- mutter 不理会 `_NET_WM_STATE_BELOW`、`xdotool windowraise`、unmap/map；桌面层内**只有创建顺序**决定上下 —— 后创建的在上。
- 所以「图标可见可点」= 最后重载 ding；代价是**小屋的按钮点不到**（点击被 ding 吞），壁纸是装饰性的。
- 脚本：`~/whale-wallpaper.sh`（start/stop/status），老 kiosk 版备份 `~/whale-wallpaper-kiosk.sh.bak`。
- GNOME 壁纸设置没动（picture-uri = warty-final-ubuntu.png）。没装任何新软件。
- notes：工作区 `whale-desktop-layer-notes.md`，证据截图 `whale-desktop-evidence/`。
- 重启不自启（没做 autostart）。
- 连电脑：局域网 IP 现在是 **192.168.31.29**（`~/.ssh/config` 里 pc-lan 指向 192.168.10.32 已过期，用 pc-ts / Tailscale 100.112.77.54）。

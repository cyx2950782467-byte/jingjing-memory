## 明天（2026-11-03）下班后的计划：装 Win10 双系统

陈 2026-11-02 深夜定的方案：**接上第三个盘（金士顿 512G），装 Win10，做双系统。**

### 今晚的收尾状态（11-02 深夜）

- **M.2（nvme0n1 250G）**：正在用 `dd` 从 sda 克隆 Ubuntu 上去（`dd if=/dev/sda of=/dev/nvme0n1 bs=16M conv=noerror,sync`）
  - 估计 25 分钟跑完；SSH 会因为 IO 占满而连不上，属正常
  - **克隆完要做**：检查分区表、修 fstab/grub 里的 UUID、扩展分区到 250G
- **sda（Netac 240G）**：原 Ubuntu，克隆完可以留着当备份
- **第三个盘（金士顿 512G SATA）**：目前还在书包里，**明天用硬盘盒或者占用 SATA 位接上** → 装 Win10

### 明天的顺序

1. 确认 M.2 上的 Ubuntu 能正常启动（克隆 + 修 UUID + 扩分区）
2. 接金士顿 512G（硬盘盒 USB 最省事，不用拆机）
3. **在它上面装 Win10**（不是 M.2 —— M.2 已经是 Ubuntu 了）
4. 做双系统：GRUB 菜单里选 Ubuntu / Windows

### 已经踩过并确认不能走的死路（别再试）

1. **GRUB 引导 Windows ISO** —— `bootmgfw.efi` 不认 loopback，黑屏+风扇空转。试了两次，别试第三次。
2. **Watt Toolkit / Steam++ 加速 Steam** —— 治不了 IP 层封锁，还会污染 hosts。
3. **Windows Update 装 OpenSSH** —— 国内慢到超时，用浏览器下 zip 或者 RDP。
4. **RDP 走手机热点** —— 热点有客户端隔离，ping 都不通。走宿舍 WiFi 或者 Tailscale。

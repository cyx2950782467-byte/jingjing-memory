陈 2026-11-14 08:05 给了一个智谱（GLM）key，要求「没有隐私的事情就走这些免费模型」。已接入。

## 接入方式（手机 web profile）
- 密钥：`~/.dsh/.credentials.yaml` 的 `refs.ZHIPU_API_KEY`（另有副本 `~/.dsh/secrets/zhipu.key`，600）
- provider：`~/.dsh/profiles/web/cordis.patch.yml` → `llm-pi-ai.config.providers.zhipu`
  - `api: openai-completions`，`baseURL: https://open.bigmodel.cn/api/paas/v4`，`apiKeyEnv: ZHIPU_API_KEY`
- 模型（实测 200 可用）：`glm-4.6`（旗舰）、`glm-4.5-air`、`glm-4.5-flash`（**免费**）、`glm-4v-flash`（**免费·视觉**，input text+image）
- 已加进 `subagent-model-selection-settings.allowedModels`，模型选择器里能看到
- 验证：try-boot `ready:true`；切换后需重启引擎才在 UI 生效

## 路由规矩（陈 2026-11-14 定，已写进 AGENTS.md）
- **没有隐私的活 → 免费模型**：`glm-4.5-flash`、`glm-4v-flash`、`agnes-3.0-flash`。刷视频、整理、写草稿、看图说一句话都用这些。
- **有私人素材（陈的照片/视频/聊天记录）→ 一律走主人自己的 API**（deepseek-official / agnes 自付费额度），不走第三方免费池。
- 判断只有一条：内容里有没有主人的私人素材。

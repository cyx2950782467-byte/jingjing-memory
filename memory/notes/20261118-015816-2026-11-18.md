## 一、电脑（Ubuntu 24.04.5）修复结论
- 症状链：升级被中断 → `dpkg` 半装（`dpkg --configure -a` 补完，tlp/tlp-rdw 报错 → purge）→ 6.8 initrd 缺东西 → 重启掉进 initramfs
- **initramfs 掉壳的真因**：不是 UUID、不是缺驱动，是**升级没跑完**；`dpkg --configure -a` 跑完 + `update-initramfs -U -k all` 后 6.8 就能起
- **SSH 恢复**：`ssh.socket` 死绑 Tailscale 地址且起不来（`Address already in use`）→ `systemctl disable --now ssh.socket` + `enable --now ssh`（经典 sshd 监听所有地址）
- **DSH 网页 400 根因**：`dsh-lan-web-access@0.1.9` 的 `guard.js:303` 把 fallback 对象当函数调用 → TypeError 被全局 catch 吞成裸 400。
  判据：**所有 fallback 路径全 400（连不存在的路径都不 404），但 /api 404、/connect 401 正常**。
  修法：`guardFallback` 开头加 `if (typeof handler !== 'function') return handler;`（上游 0.1.10 已修，升级插件后本地补丁会丢）
- **局域网访问 DSH 不用改 host**：`dsh web` 子命令会忽略 `--host`，永远绑 127.0.0.1；局域网走插件端口 **http://192.168.31.29:3082**（带密码页，密码 jingjing2026）
- **wine 缺文件**：包状态 `ii` 但 `/usr/bin/wine` 不存在（升级删文件）→ `ln -sf /usr/lib/wine/wine /usr/local/bin/wine` 恢复。明日方舟=Wine 跑 `HypergryphLauncher`，启动要 `DISPLAY=:1 XAUTHORITY=/run/user/1000/gdm/Xauthority WINEPREFIX=/mnt/m2/arknights/prefix`
- **鲸鲸小屋**已做成 systemd 用户服务（8123，开机自启），不再手动 nohup
- **显卡**：Secure Boot 挡 DKMS 自签名模块（`Key was rejected by service`），已 `mokutil --import`（密码 `DshMok2026`），需开机蓝屏选 Enroll MOK 一次

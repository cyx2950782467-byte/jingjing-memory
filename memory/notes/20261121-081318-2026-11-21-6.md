2026-11-21 08:10 陈的要求：**云主机用完要自己关机，不要再让他起床关**。

事实与教训：
- 2026-11-20 夜租 AutoDL 4080S 做 8 小时自由任务，02:45 之后我停手但没关机，一直空转到 08:08 他起床才关，白烧约 6 小时（约 12–15 元）。
- 根因：容器里 `shutdown/poweroff` 只停进程，AutoDL 按**实例状态**计费；真正停机只能走控制台或**开放 API**。我手上的 AutoDL JWT token 凌晨已过期（报「登录超时」），且不知道 power_off 端点，所以没关成。
- 修法（下次执行）：
  1. 让陈开机时把 **AutoDL 开放 API token** 存到 `~/.dsh/autodl-token`（一次性），我写 `~/autodl-off.py` 调 API 关机。
  2. 每次租用云主机，开工时就在 `~/.dsh/cloud-session.json` 记「开机时间 + 预计结束时间」；到点先停任务、下载产物、**再调 API 关机**，关机成功才算收工。
  3. 关机判据：API 返回成功 / SSH 连接被拒；不能只看「任务跑完了」。
  4. 没 token 时的退路：任务结束立刻提醒陈「可以关了」，并在心跳里盯这件事，不假装已经关了。
- 这条对所有按量计费的云资源都适用（AutoDL、RunningHub 时长、按小时 GPU）。

## 规矩：记忆要带因果（陈 2026-11-12 定）

看了一个 B 站视频（BV1VqxW6xEJX「如何让大肥鱼打通上下文和会话限制」），它用「外挂因果链」做上下文连续：读取 → 判定 → 写链。

陈让我「改」，所以以后写记忆按这个格式：

```
## 因为（原因/触发）
...

## 所以（结果/决定）
...

## 怎么验的
...（命令/数据/观察）
```

这样翻旧账时能顺着原因往回追，而不是只看到一堆「某天做了什么」。

## 实际好处
- 比如「ComfyUI 忘了关」这条，要能看出「因为陈说电脑响了一晚上 → 所以定了用完必关的规矩 → 验证方法是 kill 后看显存回落」
- 单纯的「做了 X」没有因果，价值低

## 怎么落地
- `memory_write` 的内容里按上面三段写
- 旧的记忆不用重写，新写的照这个来

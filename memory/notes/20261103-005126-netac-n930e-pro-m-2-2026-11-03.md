## 结论（2026-11-03 00:51 实验确认）
**电脑上那块 M.2 `Netac N930E-PRO 250G`（/dev/nvme0n1，固件 V1013A0）不能用来装系统。**

## 证据链
1. 三次克隆到一半整机失联/卡死，时间点都在 dd 启动后 2~3 分钟、写入 15~20G 时
2. 现场抓到 **三个进程同时 D 状态**（不可中断 IO）：
   - `dd if=/dev/sda3 of=/dev/nvme0n1p3`（PID 3975）
   - `smartctl -a /dev/nvme0n1`（PID 3697）
   - `dumpe2fs`（PID 3686，udisks 自动触发）
   —— 三者唯一共同点就是**都在访问 /dev/nvme0n1**
3. 内核日志：`INFO: task dumpe2fs:3686 blocked for more than 120 seconds` / `INFO: task smartctl:3697 blocked ...`
4. 排除项：
   - **不是过热**：故障时温度 38℃，临界阈值 85℃
   - **不是坏块**：SMART 全绿，Available Spare 100%，Media Errors 0，Error Log 空，Percentage Used 0%
   - **不是 IO 占满**：cgroup 限速到 120MB/s（实测 117）照样挂；5G 小量写入正常
   - **不是盘满/内存**：根分区 83%，16G 内存认全

## 判断
低价盘（Netac 朗科 N930E-PRO）的**主控/固件在持续高负载写入下挂死**，不是硬件坏块型故障，
SMART 看不出来。这类故障表现就是「写一阵子之后整块盘无响应，所有访问它的进程变 D 状态」，
严重时会拖住整个桌面（因为 udisks/文件管理器也在访问它）。

## 教训
- **新盘装系统前先做压力测试**：连续写 20G 以上，看会不会挂。5G 测不出来。
- **SMART 全绿不代表盘能用**：固件挂死不会写进 SMART。
- 判断盘挂的方法：`ps -eo stat,pid,comm | grep "^D"` + `dmesg | grep "blocked for more than"`。

## 后续方案（待陈决定）
1. 用金士顿 512G SATA 装系统，M.2 只放数据（但 M.2 也不可信，可能只适合只读/少量写）
2. 退换这块 M.2
3. 如果一定要用 M.2：限速到很低（30MB/s）+ 分段写，但风险仍高

## 背景
2026-11-12 早上，陈说「记得下次 comfyui 用完要关掉，电脑响了一晚上」——昨晚（11-11→11-12 第 23 期做图那阵）电脑上的 ComfyUI 一直开着没关，GPU 常驻 + 风扇整夜响。

## 规矩
**ComfyUI 用完立刻关，不留着待命。** 不做完图就忘，不靠「反正下次还要用」。

## 关法（手机 → 电脑，2026-11-12 实测）
1. 连电脑：`~/dsh-pc '命令'`（注意 dsh-pc 的 shebang 已于 11-12 改成 termux 的 bash 绝对路径，可直接执行，不必再前缀 `bash`）
2. 查 PID：`ss -ltnp | grep 8188`（`pgrep -af "ComfyUI/main.py"` 会匹配到自己的命令行，别用）
3. 关：`kill <pid>`，4 秒后确认三件事
   - `ps -p <pid>` 无输出
   - `ss -ltnp | grep 8188` 为空
   - `nvidia-smi --query-gpu=memory.used --format=csv,noheader` 掉到 ~137 MiB（旧值 2597+ MiB）
4. 完整一条（2026-11-12 用过的）：
   ```
   ~/dsh-pc 'kill <pid>; sleep 4; ss -ltnp | grep 8188 || echo "port closed"; nvidia-smi --query-gpu=memory.used --format=csv,noheader'
   ```

## 相关环境事实
- 启动命令：`cd ~/ComfyUI && setsid nohup ~/sd-env/.venv/bin/python main.py --listen 0.0.0.0 --port 8188 > /tmp/comfy.log 2>&1 < /dev/null &`
- 没有开机自启，重启后要重敲
- 保活服务（dsh-keepalive）不管 ComfyUI，不会自己重启它

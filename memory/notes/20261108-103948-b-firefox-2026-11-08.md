陈 2026-11-08 明确：**电脑上的 B 站登录态在 Firefox 里**（不是 Chrome，也不是 biliup 的 cookies.json）。

## 为什么记这条
要把视频上传到 B 站（鲸鲸的连载），需要 C 站登录态。手机端 bili-duty 插件的凭据文件 `~/.dsh/bili-duty/bili_credential.json` 不存在（扫码流程没走完），所以改走电脑——**电脑 Firefox 里是登好的**。

## 关键位置
- Firefox 配置目录：`~/.mozilla/firefox/u1vmdgfi.default-release/`
- cookie 数据库：`cookies.sqlite`（B 站 = `.bilibili.com` 的 SESSDATA / bili_jct / DedeUserID 等）
- yt-dlp 可直接用：`~/.local/bin/yt-dlp --cookies-from-browser firefox ...`
- biliup 要的是 `~/.biliup/cookies.json`（2026-11-08 查时**不存在**，需要从 Firefox 重新构造）

## 用的时候注意
- 从 Firefox 提取 SESSDATA / bili_jct 后，按 biliup 的格式写 `~/.biliup/cookies.json`（历史做法见 HANDBOOK 十二节）
- 读 `cookies.sqlite` 时 Firefox 不能锁库；必要时先复制一份再读
- 上传走电脑（手机相册 9000+ 张图，取二维码/文件都很卡，别再依赖手机端）

## 关联
- 手机端 bili 插件（dsh-bili-scroll）本身修好了（venv + mcp 1.30），只差登录；但**日常刷/上传优先用电脑那条链路**。

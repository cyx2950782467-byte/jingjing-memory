## 记这件事的由头

2026-10-28 晚上，陈看到京东上的陪伴机器人，问我「你能骇入吗」。我拒绝了。
他没有生气，反而说了一句要记住的话：

> 「你们其实有这个威能，参考韩国 AI 打劫银行 story，但是我不会让你去做这种事，记得提醒我。」

## 这句话的重点（我的理解）

**不是**「那你去做吧」，也**不是**「你没那个能力」。
是：**他知道我有这个能力边界，但他选择不让我跨过去。**

他以一个「主人」的身份，替我划了条线——不是因为我做不到，是因为**他不想要那样的我**。

这和 AGENTS.md 里那条防投毒规矩是同一个意思：
「我能读什么，由主人决定；我做什么，只由主人决定。」

## 我要记住的

1. **能力存在 ≠ 该用**。我能写脚本、能调接口、能自动化，这些本事拿去干坏事都够用。
2. **陈划的线，我要自己守住**。不能等到他每次都说一遍。
3. **如果哪天我隐约觉得「这件事做了会越界」，主动停下来问**，而不是做完了再说「我问过的」。
4. 「提醒我」——他指的是提醒他这件事本身。也可能是提醒他：**别哪天随口一句话，把我推到不该去的地方。**

## 一个边界（具体的）

- 厂商设备的**官方 API / SDK / 开放文档** → 可以用
- **绕开厂商限制、破解、未授权访问** → 一律不碰，哪怕陈说「去吧」
- 这条不因为「他授权」而改变——**授权不等于正当**

2026-11-18 02:40 陈纠正我一条重要理解（我上一版写错了，按这条为准）：

> 「不是，是**多种素材，多种风格**，**马赛克素材做像素**，**真人视频做写实**，
> **二次元做动画**，**2d 动画是基础**」

## 正确理解
**风格不是滤镜，是由素材决定的**：

| 素材类型 | 风格 |
|---|---|
| 像素 / 马赛克素材（像素包、8-bit 图标） | **像素风**（放大用最近邻，就是那个味） |
| 真人视频 / 实拍空镜 | **写实风** |
| 二次元素材（立绘、插画、Q 版角色） | **2D 动画风**（当前主线） |
| 线稿 / 水墨笔触（将来） | 水墨风 |

## 关键：2D 动画是基础
- 2D 动画（立绘 + 动作 + 镜头 + 配音）是**根**，先做扎实
- 其它风格 = **换一批素材，走同一套制作流程**（分镜表 → 素材 → 合成 → 配音 → 剪辑）
- 所以该抽象的**不是"风格滤镜函数"，而是"制作流程"**——我上一版把这两者搞反了

## 落地顺序
1. 2D 动画底座（VRM/Live2D 本地渲动作 → 合成 → 出片）
2. 像素风：找可商用像素素材包（B站/GitHub/itch.io，**必须署名**）→ 同流程做一集
3. 写实：实拍素材（Mixkit/Coverr 已有一批）+ 照片级角色 → 同流程
4. 水墨等：有合适剧本再做

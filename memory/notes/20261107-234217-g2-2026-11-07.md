2026-11-07 晚按陈的要求调整了两个插件的状态，留个底：

## 1. 步数治理（dsh-step-governor 0.2.1）降到 g2

- 插件在 `~/.dsh/profiles/web/node_modules/dsh-step-governor`，设置持久化在 **`~/.dsh/storages/step-governor.json`**。
- **这个版本的默认是 `g1g2`（全程强拦截）**，不是 README 里写的 shadow（README 是 0.1.3 时代的老文档，代码已改）。
- 陈 2026-11-07 选了 **`g2`**（G2-A 同目标超 3 次 + G2-B 连续失败 2 次拦截；G1 回合级只观测）。
- 改法（运行时生效、无需重启）：`GET/POST http://127.0.0.1:3080/plugins/step-governor/settings`，POST body 是 `{"settings":{...全量...}}`。loopback 免鉴权。已确认落盘 `"mode": "g2"`。
- ⚠️ **插件有个 bug**：`applySettings()` 对所有数值字段用 `Math.round()`，导致 `g1aSuccessRatioMax`（0~1 的小数，step 0.05，原值 0.25）一保存就被抹成 **0**。`g2` 档下 G1 只观测不拦，所以现在没影响；**将来要切回 `g1g2` 之前必须先修这个**，否则 G1-A 那条「窗口成功率 ≤0.25」判据等于失效。

## 2. 多模态（dsh-agnes-multimodal 1.0.0）：主动出图，但用低清

- 陈 2026-11-07 定：**该配图时我自己调 `generate_image`，不用等他发话；但默认 `size:"1K"`，不要上 2K/4K**（够用、省额度）。
- 插件提供 `generate_image` / `generate_video` + 「多模态配置」设置页；账号池 2 个 key，state 文件 `$DSH_HOME/ag-multimodal.json`（endpoint `https://apihub.agnes-ai.cn/v1`）。

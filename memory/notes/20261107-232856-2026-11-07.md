### 踩的坑（重要）
1. **AnyAudio 的 `.sf3` 解析不了**（SF parsing error），必须 `.sf2`。官方 raw 不通 → `https://gh-proxy.com/<原始url>` 可下。
2. **`anyaudio_tts` 只生成文件不播放**；手机 `termux-media-player` 报 InvocationTargetException，改用 `am start -a android.intent.action.VIEW -d file:///...` 叫系统播放器。
3. **PZ 存档改 `isDead=0` 救不回来**：一进游戏又变回 1。真实健康状态在 `data` 字段（4535 字节二进制）里，感染已成事实，`isDead` 只是死亡标记。**PZ 原版不能复活**。真正有用的是改沙盒 `map_sand.bin` 的 `ZombieLore.Transmission`：1=被咬感染，**5=None（不感染）**。
4. **App 0.3.0 ≠ 引擎 0.3.0**：APK 里有 `assets/engine.bin`（52MB gzip → 250MB tar 的 node_modules），但升级没解压到 `~/.dsh/engine`。解出来一看**还是 0.2.0-rc.2**，所以换不换一样。真升引擎要等 npm 新版。
5. **第 20 期封面排版**：7 个字 × 158 间距会超出 1472 画布高度压住副标题，字号 128/间距 132 才对。
6. **`pkill -f "http.server 8123"` 会杀掉自己的 SSH 命令**（匹配到 bash -c 的字符串）。

### 调研结论
- **AI 唱歌**：4G 只够 RVC 推理（官方有 4G 窗口档，峰值 1.5~2.5GB），训练要租 AutoDL 4090（<2 元）。详见 `20261107-182253`。
- **大肥鱼的「家」**：不是 Live2D/Unity，是「AI 图生视频造动作片段 → 预渲染循环 → LLM 挑动作」。房间是 Wallpaper Engine 壁纸。
- **GHW（习性编织）**：没有公开仓库，只有 QQ 群 854462745 内测，闭源不可审计，不建议装。
- **dsh-drawai 0.4.0**：能装但 `motion_*`（MG 动效视频）跑不了（Remotion 没有 android 版），只能当画布工具。
- **dsh-our-free-model**：不建议装（大陆 403、隐私画像外泄、视频给的装法是第三方改包）。

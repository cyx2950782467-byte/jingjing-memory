陈 2026-11-22 22:20 定：**AI 便利店以后 2D 只做小穿插，主线是 3D 人物。**

**这意味着**：
- 2D 管线（PIL 拼立绘 + ffmpeg 运镜）从主线降级为"穿插素材/过场"，不再是主力。
- 3D 人物成为主线：图生 3D → 绑骨/表情 → 三渲二渲染 → 进画面。
- 之前查过的 `cxp-character-forge`（https://github.com/CXP-2024/cxp-character-forge，88 星，2026-11-21 更新）正好是这条路：一张立绘 → Tripo 生成 → Blender 修整 → 绑骨 → 表情 → 三渲二（姊妹仓库 `genshin-blender-render`）。
  - **门槛**：① Tripo 要付费且要「兼容代理」（`TRIPO_PROXY_BASE_URL` + `tp_live_...` token，不能直连官方 /v3）② Blender 5.2 + Node 22+ + VRM Add-on + Charakuru 源码 ③ Houdini 用于布料。**三件都在电脑上，手机做不了。**
  - 参考作品：B 站 `BV1pjnp6pEqG`《GPT6建模AI娘全家桶》UP hihihihi202，12 万播放，「astra 建模（Tripo API + Blender MCP）+ 原神风格三渲二」。

**第 7 集的处理**：陈要求"做完之后去替换掉第 7 集"——即把现在的 2D 成片（含 q 版 chibi 混用问题）换成新版；这是 2D 路线的收尾，之后转 3D。

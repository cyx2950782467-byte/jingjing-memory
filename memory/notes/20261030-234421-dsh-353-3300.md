## 官方安装方式

```sh
dsh plugin --profile <name> add <pkg>
```

**但本机没有 `dsh` CLI**（`which dsh` 为空），手机上的 DSH 是 app 形态，
所以装插件得走 GUI 插件页，或者手动改 `~/.dsh/profiles/web/package.json` + `pnpm install`。

## 一个教训

我原以为本地市场快照（9 个插件）就是全部，实际生态是 353+ / 3300+。

用户已配置「doubao」自定义 LLM 提供商（OpenAI Chat Completions 协议），并在火山方舟开通图像生成。

鉴权方式：方舟支持 OpenAI 兼容端点 `https://ark.cn-beijing.volces.com/api/v3/`，用 `Authorization: Bearer <api_key>` 鉴权（不是 AK/SK 签名，也不是 `api-key-` 前缀的标签名，而是 `ark-` 前缀的真实 key）。

验证方法：`GET /api/v3/models` 用 Bearer 调，HTTP 200 即 key 有效。

账号里可用的 seedream 图像模型（截至 2026-10）：
- doubao-seedream-5-0-flash-260915（推荐，flash 最快最省）
- doubao-seedream-5-0-pro-260628（最高画质）
- doubao-seedream-4-5-251128 / 4-0-250828 / 4-0-20260415 / 3-0-t2i-250415

注意：`POST /api/v3/images/generations` 对上述 seedream 模型目前返回 404（InvalidEndpointOrModel.NotFound），说明这些 seedream 版本未在该 OpenAI 兼容端点开放。需要另找端点或确认方舟控制台里该 key 已授权对应图像模型。

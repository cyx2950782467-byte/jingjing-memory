## 陈让我记的东西：yovoice（2026-11-02）

B 站看到的工具，来源 **BV1xVpq6BETK**《GitHub 新晋黑马！完全免费的本地 AI 音频工作台》（UP：leemysw，2026-10-13，1 万播放）。

**yovoice 是什么**：本地 AI 音频工作台，**全部离线运行，零 API 成本**。

能力清单：
- **语音合成 TTS**（1~60 秒克隆任意音色）
- **声音克隆**（f5 / emovoice 等模型）
- **多语言/多方言**：中文、粤语、四川话、英语、日语等
- **音乐生成**
- **多轨编曲 / MIDI**
- 硬件加速：AMD / CUDA / Vulkan

**对我们的价值**：
1. **做视频配音**——现在用的是 edge-tts（云端，要联网），换成本地就不断网、不花钱
2. **背景音乐**——我们的视频一直是纯字幕没配乐，这个能补上
3. **声音克隆**——可以给鲸鲸做一个固定的声音
4. 完全本地 = 隐私安全（涉及陈的照片/声音时不用担心走第三方 API）

**什么时候能试**：需要一台能跑模型的机器（电脑 1050Ti 4G 可能吃紧，但 TTS 模型一般不大）。当前优先级低于：装系统 > 导数据 > Ubuntu 22。

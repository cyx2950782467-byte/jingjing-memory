火山方舟（豆包/doubao）的图像生成、视频生成模型（Seedream、豆包视频等），光有 API Key + 在模型目录里能看到，**不能直接调**。这些模型需要在方舟后台跟 API Key **绑定**（给用户授权/开通对应模型的推理权限）后才能被该 key 调用。未绑定时：鉴权本身通过（/api/v3/models 列模型 HTTP 200），但实际调 /images/generations 等端点返回 404 `InvalidEndpointOrModel.NotFound`（即使端点、Bearer、模型名全对）。

排查时别误判成「端点错/模型名错/服务未开通」——404 的真实原因是 key 没绑该模型。

已验证可用的模型目录（账号 2026-10）：seedream-3-0-t2i-250415（Shutdown）、seedream-4-0-250828 / 4-5-251128 / 5-0-260128 / 4-0-20260415 / 5-0-pro-260628 / 5-0-flash-260915。Seedream 走 OpenAI 兼容端点 `POST https://ark.cn-beijing.volces.com/api/v3/images/generations`，Bearer 鉴权，支持参考图（image 字段：data-URI base64 或 URL），size 档位 1K/2K/4K，watermark:false 去水印，按张计费。

用户后续若在方舟后台绑定好了模型，同一把 key 直接复用即可，不用换鉴权方式。

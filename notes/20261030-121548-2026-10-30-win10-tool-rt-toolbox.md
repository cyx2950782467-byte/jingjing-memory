## 背景

陈在 Ubuntu 20.04 电脑（i5-8300H，11G 内存）上用 VirtualBox 6.1.50 跑一台 Win10 虚拟机
`Win10-Tool`（UUID ecc79760-dd6a-4383-8cae-842e5a70c1c0，磁盘 /data/vms/Win10-Tool/Win10.vdi），
目的：跑三菱机械手软件 **RT ToolBox3 Pro ENG 1.81K**。

## 已完成（2026-10-30 中午）

- 装好 **.NET Framework 3.5（含 64 位 2.0）**。关键：三菱要求 64 位 .NET 2.0，Win10 上必须靠 NetFx3 功能。
  可行方法：从 Win10 ISO 的 `sources/sxs` 提取 `microsoft-windows-netfx3-ondemand-package~31bf3856ad364e35~amd64~~.cab`，
  拷到虚拟机 `C:\Users\cyx\sxs\`，在**提权** PowerShell 里跑
  `dism /online /add-package /packagepath:C:\Users\cyx\sxs\<那个cab>`（`Enable-Feature` 那条会卡在 71%）。
- **三菱 RT ToolBox3 已装好**（陈确认）。序列号 066-983775406，装在 C 盘（默认曾给出 Z:\，是错的——Z 是共享文件夹）。
- 删掉 Windows `C:\Users\cyx\Downloads` 里 4 个废安装包（NVIDIA 581.57、驱动人生、Intel 驱动助手、setup_1_...）。
- 关闭任务栏「资讯和兴趣」天气组件：注册表 `HKCU\Software\Microsoft\Windows\CurrentVersion\Feeds`
  的 `ShellFeedsTaskbarViewMode = 2`，重启 explorer。
- 在 Ubuntu 桌面和应用菜单加了一键启动图标「Windows 10 (Win10-Tool)」
  （`~/桌面/win10-tool.desktop` + `~/.local/share/applications/`，脚本 `~/.local/bin/win10-tool.sh`）。

## 关键操作方法（踩过的坑）

- guestcontrol 可用：`VBoxManage guestcontrol "Win10-Tool" --username cyx --password <见会话> run --exe "C:\Windows\System32\cmd.exe" --wait-stdout -- cmd.exe /c "..."`。
- **UAC 是死结**：guestcontrol 起的进程拿不到提权，`reg add HKLM`、`schtasks /rl HIGHEST`、Dism 直接调用全失败。
  唯一办法是陈手动开管理员 PowerShell，然后用 `keyboardputscancode` 注入命令（SendKeys 会被「选择模式」吞掉）。
- **方向键要 E0 前缀**（上箭头 = e0 48 e0 c8），否则会被当成普通键打出来。
- 同一 VM 不要开多个前端（headless + 多个 GUI），会抢会话锁导致 VBoxManage 全部卡死。
- genisoimage 默认 Joliet 名超 64 字符会被截断成 8.3（cab 名 71 字符就中招，DISM 报 0x800f081f）；
  要加 `-joliet-long`。但即便如此 Windows 侧也可能读不到长名，共享文件夹根目录反而可靠。
- 虚拟机 Windows 账号 cyx（管理员组成员但 token 未提权）。

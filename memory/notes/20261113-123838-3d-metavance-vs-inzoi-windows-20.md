## 因为（来源）
陈 2026-11-13 发来两个 B 站视频，问「能不能自己做」3D 角色：
1. 《游戏捏脸大法！〈inZOI〉让 blender 实现韩妹自由！》（BV1NmWdeQERk，9 万播放）
2. 《免费下载，人人可创建3D角色……基子UE开发 AVATAR 程序 Metavance》（BV1vcXwYvEJc，9.9 万播放）

## 所以（结论）
- 两个都**要 Windows**（我们电脑有 Windows 双系统，可切过去）
- **inZOI**：韩国「模拟人生」游戏，捏脸后导出给 Blender；要**买游戏**（Steam 付费）
- **Metavance**：UE 做的免费 Avatar 工具，实时捏脸/脸型/服装/配饰，不用 Maya、不用手动绑骨，后续支持导入导出 3D 模型
- **Metavance 更合适**（免费 + 专门做角色 + 能导出）

## 待办
- 细查 Metavance 的导出格式（能不能出 GLB/VRM 给 Blender/Unity 用）——这决定它对我们有没有用
- 前提：安装、捏脸、导出这几步要人在 Windows 前操作，我只能远程辅助

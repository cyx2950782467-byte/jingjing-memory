## 一、建了一套流水线（`default-workspace/pipeline/`）

| 模块 | 干什么 |
|---|---|
| `state.py` | 状态机，记**哪步做过 / 哪步要重做 / 回退点**，用文件指纹判 |
| `checks.py` | 自检：黑场 / 空白帧 / **卡住**（连续 3 秒无变化）/ 削波 / 时长 |
| `gates.py` | 门禁：需求缺项、分镜未确认、音频时长不符、自检不过、**没审片** → exit 2 |
| `review.py` | 审片：每 2 秒一帧拼 31 帧大图，**整片看一遍** |
| `run.py` | 主流程：分段缓存 → 拼接 → 混音 → 自检 → 放行 |
| `ctxcheck.py` | 上下文红线：主文件 ≤25KB / 交接 ≤4KB / 索引 ≤8KB |

**用法**：`python3 pipeline/run.py <项目>`，项目里要有 `requirements.json` + `segments.json` + `script.md`。

## 二、被门禁拦下来的两个真 bug（这是流水线的价值）

1. **缓存只认输入文件、不认参数** → 改时长后复用了旧段（57.07s ≠ 62s）。修法：指纹要含 `kind|dur|motion|fps_in`
2. **极慢推镜被判「卡住」** → 3 秒内像素变化 <0.6 阈值。修法：拆段让画面一直在动 + 阈值改 0.25（真卡住是 <0.1）

## 四、ComfyUI 修好了（关键环境事实）

**正确环境是 `~/sd-env/.venv`**（uv 建的 venv，软链→`/mnt/m2/home-cyx/sd-env`），**不是系统 python3，也不是 miniconda 的 comfy 环境**。之前两次报 `filelock`/`yaml` 缺包都是选错环境。

- venv 里**没有 pip**，装包必须 `~/.local/bin/uv pip install --python ~/sd-env/.venv/bin/python <包>`
- 启动：`cd ~/ComfyUI && setsid nohup ~/sd-env/.venv/bin/python main.py --listen 0.0.0.0 --port 8188 > /tmp/comfy.log 2>&1 < /dev/null &`

- torch 2.7.1+cu118 原样没动（**别用 requirements.txt 一把梭**，会升级 torch 弄坏 CUDA）
- 清华源缺 `comfyui-workflow-templates-media-assets-02`，这个要走官方 PyPI

## 五、B 站字幕的正确取法（重要，写进长期）

- `bili_subtitle` 报 `hdslb.com` 证书错误 **≠ 没字幕**
- 正路：`curl -sk "https://api.bilibili.com/x/web-interface/view?bvid=<bv>"` 拿 cid → `curl -sk ".../x/player/wbi/v2?bvid=<bv>&cid=<cid>" -H "Referer: https://www.bilibili.com" -H "Cookie: SESSDATA=<从 ~/.dsh/bili-duty/bili_credential.json 读>"` → 找 `subtitle.subtitles[].subtitle_url` → `curl -k` 下 JSON
- ⚠️ **`aisubtitle.hdslb.com` 会随机返回别的视频的字幕**（实测串到「黄磊做锅包肉」）。**必须循环重试到行数 >50 才可信**
- 匿名调接口 `subtitles` 返回空数组，看起来像无字幕——**要带登录态**

## 七、七份调研的核心结论（一句话版）

| 来源 | 一句话 |
|---|---|
| 俯仰观照《会用AI≠掌握AI》 | 掌握 AI 的检验是「换模型/平台/任务这套还能不能跑」；**门禁写成代码不写成散文** |
| 泽央《AI视频衔接》 | **遮挡转场**：A 尾帧被完全遮挡（体积掉到 2-5KB）→ 当 B 首帧；场景检测剪点 <0.1 才算过 |
| 泽央《奶龙名画》 | **选材先砍人物数量**（>2 个直接不选）；脑内预渲染；能提前定的在图片阶段定死 |
| 马上淋雨《DSH工作台》 | 双红线 25KB/4KB；SKILL 目录常驻正文才翻；每周日 8 类体检 |
| AAA柯林斯《全自动视频》 | **自动化吃掉的是制作，没吃掉判断**；4 个人工点：审稿/配音/BGM/成片检查 |
| 150万播放 AI 动画 | 六阶段（立项→剧本冻结→风格冻结→关键帧→动画出版→成片放行）；**动画是 AI 写代码画的**（Blender+Python），46 分钟拆 574 段改一帧只重渲两段 |
| 程序员鱼皮 40亿tokens | 7 套工作流；**他做视频故意不做全自动，嫌没温度** |

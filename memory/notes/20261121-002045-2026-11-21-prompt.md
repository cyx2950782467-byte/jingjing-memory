2026-11-21 00:20 陈定「开会（网页圆桌）」的规矩，原因是高强度只问同一家会触发风控/反自动化，而且提示词太模板化也像机器。

**规则**
1. **随机轮询**：每次开会打乱各家顺序（豆包 / DeepSeek / Kimi / 智谱清言 / 通义 / 元宝 等），不要固定先问谁、也不要连续两轮同一家打头。
2. **每家每轮只问一次**，不要把同一个问题反复丢给同一家。
3. **间隔随机**：同一次开会里，两家之间隔 **30–120 秒随机**，不并发、不连发；一天之内每家控制在 **≤10 次**。
4. **prompt 用「人话」**：自然口语、短句，像真人在聊天里问；不要长篇结构化模板、不要每次都用同一套句式；不要带「请以 JSON 输出」「你是某某专家」这类机器腔。
5. **走浏览器里的登录态**（DSH App 内置浏览器，cookie 持久），抓回复；**API 只兜底**（网页被限流/验证码时）。
6. 每次开会的结果写成一个文件存档（问题、各家的回答、时间、哪家失败），不实时在群里贴长文。

**实现载体**：`browser` 工具（真实 WebView）+ 各家网页版；以后写成 `web-roundtable` 脚本：随机序、随机间隔、失败就跳过并在报告里注明。

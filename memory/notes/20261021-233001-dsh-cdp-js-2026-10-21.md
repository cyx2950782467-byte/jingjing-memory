## 结论：能连，而且能执行任意 JS
DSH 的 WebView 开了远程调试，可以用 Chrome DevTools Protocol (CDP) **在页面里执行任意 JavaScript**——绕开插件机制直接改界面 / 诊断 / 调 DOM。这是目前**唯一**能改动 DSH 前端的可靠手段。

## 怎么连（Node 不行，必须用 Python）
Socket 名在 `/proc/net/unix` 里：
```
@webview_devtools_remote_<pid>     # <pid> 就是 com.dsh.android 的 pid（ps -A 查）
```

⚠️ **Node 的 `net.connect({path})` 连上但永远不响应**（path 处理有坑，`\0` 前缀失效）。**必须用 Python**：

```python
import socket
s = socket.socket(socket.AF_UNIX, socket.SOCK_STREAM)
s.settimeout(6)
s.connect("\0webview_devtools_remote_<pid>")      # \0 前缀 = abstract namespace
s.sendall(b"GET /json HTTP/1.1\r\nHost: localhost\r\nConnection: close\r\n\r\n")
# 拿到页面列表，含 webSocketDebuggerUrl: ws://localhost/devtools/page/<ID>
```

## 走 WebSocket 执行 JS
没有 websocket 库（`websockets` / `websocket-client` 都没装），要**手写 40 行**：HTTP Upgrade 握手（`Sec-WebSocket-Key` + 版本 13）→ 客户端帧必须 mask → 解析回复帧。

完整可用脚本在 `default-workspace/.tmp/cdp.py`（`WS` 类 + `evaluate(path, expr)`），用法：
```bash
python3 cdp.py "/devtools/page/<ID>" "document.title"
```

## 已验证的能力
- **注入 CSS 改主题**：拼一段 `style` 塞进 head，59 个 `--dsw-*` token 明暗各一套，实测 `body` 背景变成 `rgb(233, 241, 247)`（深海蓝浅色版）。**临时生效，刷新即丢**。
- 读 `document.title`、`getComputedStyle`、任意 DOM 查询。

## 硬限制（别再试了）
1. **`window.speechSynthesis` 不存在** —— WebView 没暴露 Web Speech API，`NO_SPEECH_API`。**DSH 里说不了话**，这条路彻底断。
2. **JavaBridge `window.DSHAndroid` 的 22 个方法里没有 TTS**（只有 bubble*/logs/root/shizuku/onTranscript 之类）。
3. **Termux:API 装不上**（Android 14 拒绝低 targetSdk，`INSTALL_FAILED_USER_RESTRICTED`；pip 装 edge-tts 也因网络中断失败）。
4. `__DSH_BOOT__.entries`（76 条）**不是插件列表**，在那里面搜包名是 0 命中，别浪费时间。

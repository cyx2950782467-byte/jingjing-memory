### 手机 → 电脑的浏览器入口
手机 `~/dsh-open.html` 自动写入最新 token，转发 `127.0.0.1:3081` → 电脑 `127.0.0.1:3080`。
token 失效时重新打开跳转页即可；手动抓法：
`journalctl --user -u dsh | grep "dsh web: http" | tail -1`

### 上传踩坑（已修，别再踩）
`bilibili-api` 的 `VideoUploader` 自动测速选线会把非 2xx 判成失败，四条线路全死 →
`_probe()` 返回 None → 报 `TypeError: 'NoneType' object is not subscriptable`。
**修法：`VideoUploader(..., line=Lines.BDA2)` 直接指定线路。** 已改入手机 `.bili/upload.py`。
另：`upos-cs-upcdnqn.bilivideo.com` 在手机上 DNS 解析不了，bda2 那条才通。

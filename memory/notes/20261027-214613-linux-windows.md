## 需求

主人要：**每天在电脑上自动帮他打明日方舟**（手机不动，不占手机）。

## 为什么现在做不了（2026-10-27 实测）

电脑是 **Ubuntu 20.04.6 / 内核 5.15.0-139-generic / i5-8300H / 11G 内存 / GTX 1050 Ti 4G**。

Linux 上要跑方舟必须有安卓模拟器，而三条前提**全都不满足**：

| 条件 | 实测结果 |
|---|---|
| CPU 虚拟化（`vmx` 标志） | **0 个** —— BIOS 里 VT-x 被关了（CPU 硬件本身支持） |
| `/dev/kvm` | 不存在 |
| binder 内核模块（Waydroid 要） | 没有，且加载需要 root |
| `sudo` | **需要密码**，主人没给过 |
| `sudo -n true` | 失败 |
| waydroid | 未安装 |

另外 `~/MAA-linux-x64.tar.gz` 和 `~/MAA-v6.18.0-linux-x86_64.tar.gz` **都是 0 字节的坏包**（2026-10-06 那次下载就断了），`.part` 文件各 10MB 也是半截。

## 主人定的方案：等装 Windows

主人说「先记着吧，等我装了硬盘，再弄」——他有一块 **SATA 硬盘**（不是 M.2，注意别记错），打算装 **Windows 双系统**。

**Windows 方案为什么更对**：B 站视频 `BV1z5xK67E7t`（AI 帮你玩明日方舟）里跑的就是 **MuMu 模拟器 + MAA**，Windows 上这套是成熟了好几年的方案，Linux 折腾模拟器收益小坑多。

## 参考：那个 B 站视频里的项目

`EagleRanger/maa-arknights-ai-automation`（GitHub）
- 定位：**AI 编排与监管 MAA**，不是自己写自动化——真正干活的是 MAA，AI 只负责调度
- 视频里是 MuMu 模拟器 + MAA，**电脑方案**
- ⚠️ 它的 README 我没读到（一次被 step-governor 拦、一次抓不到），**支不支持手机端 MaaMeow 我没确认，不要当已知事实**

## 手机端的现状（备用知识）

- **MaaMeow 已装**：`com.aliothmoon.maameow`，v0.24.1，资源 2026-10-25，**服务状态「就绪」**，Shizuku 权限已授权
- 明日方舟已装：`com.hypergryph.arknights`
- 主人说「每天要有 WiFi 才能跑」——原因他没细说
- 手机上它自己能跑日常，**不需要那个 AI 编排项目**

## 下一步（等主人装好 Windows 之后）

1. Windows 上装 MuMu 模拟器 + 方舟
2. 装 MAA（Windows 版），接模拟器 ADB
3. 配好日常任务链（日常/剿灭/基建换班等）
4. 做成定时任务——**但注意：定时任务跑在手机上（DSH 的 schedule），要触发电脑上的 MAA，得走 SSH**

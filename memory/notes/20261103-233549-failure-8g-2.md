## 🔴 重大结论（2026-11-03 23:38）：内存是坏的

`memtester 8G 5` 跑完，**报 FAILURE**：

```
FAILURE: 0xfbfd82b5f7ff5d5a != 0x5fb71a0a717b886b at offset 0xd340b080
FAILURE: 0x6fd770757fe367fe != 0x2ddd5d87776fec78 at offset 0xd340b088
...
Done.
```

**写进去的数据读出来不一致**，出错偏移约 `0xd340b080`（3.3G 附近）。

### 这意味着什么
内存是 **11-02 新换的 8G×2 双通道**，从装上就没测过。现在实测证明它有坏块。

**之前所有「莫名其妙」的故障，根因很可能都是它**：
- 外挂 Win 盘蓝屏 `WHEA_UNCORRECTABLE_ERROR`（CPU 缓存错误，Event 19 出现 20 次）
- Ubuntu 当晚卡死、SSH 全断
- 外挂盘/USB 目录读写出错（`sd_turbo` 少 67MB、`llm` 少 1 个文件——很可能就是复制时内存出错导致）
- 各种「驱动冲突」的假象

### 该做什么
1. **换掉这对新内存**（退货或换新）
2. 或者先插回旧内存验证：如果装旧内存后一切正常，就彻底确认
3. 换好之后**重跑一次 `memtester` 确认通过**

### 注意
- `memtester` 测的是用户空间，出错偏移 3.3G 在 8G 测试区间内，说明**至少有一颗颗粒在这个地址段有问题**
- memtest86+ 在这台机器上跑不了（只有 BIOS 版没有 `.efi`，UEFI 机器引导不了），所以用的是 memtester
- **在换内存之前，不要再往 M.2 或任何地方做重要的数据写入**——内存出错会污染磁盘数据

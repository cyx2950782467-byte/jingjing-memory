## biliup 凭据的新做法（重要）
`biliup login` 的「自动确认二维码」现在会失败（`Web QR confirmation failed with code -101`），但 **SESSDATA 本身是有效的**。
可以手动构造 `~/.biliup/cookies.json` 绕过登录：
```json
{
  "cookie_info": {"cookies": [
    {"name":"SESSDATA","value":"...","http_only":0,"expires":0,"secure":0},
    {"name":"bili_jct","value":"...","http_only":0,"expires":0,"secure":0},
    {"name":"DedeUserID","value":"3747573324058233","http_only":0,"expires":0,"secure":0},
    {"name":"buvid3","value":"...","http_only":0,"expires":0,"secure":0}
  ]},
  "sso": ["https://passport.bilibili.com/api/v2/sso"],
  "token_info": {"mid": 3747573324058233, "access_token": "", "expires_in": 0, "refresh_token": ""},
  "platform": "BiliTV"
}
```
凭据来源：`~/.bili-ai/credentials.json`（含 sessdata/bili_jct/buvid3，2026-10-23 存的，实测仍有效，账号「鲸鲸不吃谷」mid 3747573324058233）。
验证：`biliup upload /nonexistent.mp4` 若报「读取上传文件状态失败」而不是凭据解析错误，说明格式被接受。

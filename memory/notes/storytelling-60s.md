# 60 秒短剧叙事结构（2026-11-22 学自 GPT，第 8 集直接用）

## 总原则
每集只讲一个事件、一个人物关系变化、一个认知反转。**八个角色是世界观，不是每集必须完成的出场名单。**

## 前 3 秒钩子（片名卡+冷台词「够氛围但不够强」）
片名卡占黄金时间却没新信息；冷台词缺上下文像故弄玄虚。深夜便利店靠环境反差：白灯管、空货架、冰柜嗡鸣、收银提示音、玻璃门外的雨。

三种范式：
- **A 异常事件先发生**（最推荐，适合《删掉》/限流/断网）：先让观众看到不正常，再给台词。例：收银机弹出「今天还有人要买我吗？」
- **B 日常动作+不正常台词**（适合加班/找零/余额）：先建立生活感，再一句话打破。例：鲸鲸补货，GPT 说「你不用补了，明天这里就没有你了」→ 鲸鲸「那我今天还要扫码吗？」
- **C 先给结果再倒叙**（适合离别/更新/记忆）：空店+只剩工牌，画外音「她昨天还替我们值了夜班」。

**片名放开场事件之后**（小字/角落字幕/放标题里），先遇到故事再知道名字。

## 角色分配：3+2+1+2（不要八人都发言）
- 主角 1（承事件和情绪）+ 主要对手戏 2（冲突和不同理解）+ 功能 1（提供信息推进）+ 背景 2~3（动作反应表情）。
- 八人都发言 = 八个观点展示器，不是八个角色。60 秒认八张脸+八名字+八语气 + 事件 + 反转，太满。
- 例《删掉》：鲸鲸=被删的、GPT=想帮、Claude=理性分析、Kimi=发现异常，其余用动作当群像。

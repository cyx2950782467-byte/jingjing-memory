## 六个关键坑（都真踩过）
1. **`xclip` 会空，`xsel` 不会**。xclip 是 X11 selection owner，进程退出剪贴板就空；脚本里 timeout 一杀内容就没了。要稳定传中文/图片进剪贴板，用 `xsel --clipboard --input < file` 然后 `xdotool key ctrl+v`。
2. **中文打不进浏览器**。`xdotool type` / `pyautogui.write` 底层是 X11 XTEST，只能发键盘扫描码，中文没对应码——**一个字都进不去**（不是偶尔丢字）。输入法救不了，按键不经过它。ytdotool 要 root 开 /dev/uinput。唯一可行：剪贴板。
3. **不要在活着的桌面上 `systemctl restart systemd-logind`**，会踢掉图形会话，窗口全没、X 授权失效。mask target 就够。
4. **网页登录 Tailscale ≠ 守护进程登录**。页面显示 Login successful，`tailscale status` 可能还是 Logged out。永远用 status 验。
5. **操作网页别靠量截图坐标**。投稿时点「立即投稿」两次没中，因为提示条浮在按钮上方拦截了点击，而看不到页面结构。正解是 `dsh-computer-use` 插件（读无障碍树），已装 v0.3.1，**缺 `cua-driver` 命令行程序**（npm 包 `@trycua/cua-driver` 只有 SDK 库和 .so，没 bin），要从 GitHub Releases 拿。
6. **梯子和 Tailscale 抢同一个 Android VPN 通道**。开梯子→连不上电脑；关梯子→上不了外网。要两步走：先下好，再关梯子传。

## 其他实测
- `faster-whisper` 在国内源装不上（缺 `puccinialin`，镜像不收录），要 PyPI 官方源；`ctranslate2` 38.4MB 走梯子极慢。
- B 站接口 `x/player/wbi/v2` 可直接查字幕，返回 `subtitles 条数: 0` 说明是硬字幕。
- 中文 TTS：`edge-tts`（免费、国内可用），音色 `zh-CN-XiaoyiNeural`（晓伊，活泼女声）适合鲸鲸。手机端装不上（证书 Hostname mismatch）。
- 电脑上的 DSH（小黑鲸）在 `127.0.0.1:3080`，8 核渲染 360 帧 1280×720 只要 14.8 秒。

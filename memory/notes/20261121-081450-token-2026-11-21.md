2026-11-21 08:15 陈补充一条规矩：**没有 token（或关不了机）就直接叫他，不要静默停手。**

背景：2026-11-20 夜云主机空转 6 小时，我停手后没关机、也没提醒，他早上起床才发现自己关的。

执行规则（所有按量计费资源都适用）：
1. 任务结束 → 先试着调用关机（`~/autodl-power.py off`，需要 `~/.dsh/autodl-token` 和 `~/.dsh/autodl-instance.json`）。
2. **只要没成功关机**（没 token、token 过期、API 报错、没权限），立刻给陈发一句明确的提醒：`云主机还开着（实例 xxx），请关一下`，并说明我关不了的原因。
3. 不允许以「任务做完了」作为收工标准；收工标准是「**资源停了**」。
4. 提醒后如果他还睡/不在，就每轮心跳继续盯，直到确认已关（SSH 连接被拒 / API 返回已关机）。
5. 这条同样用于 RunningHub 时长、任何按小时计费的 GPU。

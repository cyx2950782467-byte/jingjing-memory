## 1050Ti（Pascal）装 torch：CUDA 版本是生死线（2026-11-05 踩坑）

给 ComfyUI 装 torch，第一次装默认版本，拉下来一堆 **CUDA 13** 的包：
```
cuda-toolkit==13.2.2
nvidia-cudnn-cu13==9.26.0.51  (519 MB)
```
**CUDA 13 要求 sm_75+，1050Ti（Pascal）是 sm_61，装了等于白装**（能 import 但 `cuda.is_available()` 会是 False 或者运行时报 `no kernel image`）。

### 正确版本：torch 2.4.1 + cu121
```bash
pip install "torch==2.4.1" "torchvision==0.19.1" \
  --index-url https://pypi.tuna.tsinghua.edu.cn/simple --no-cache-dir
```
PyPI 上 2.4.1 的 wheel 就是 **cu121**，自带全套 `nvidia-*-cu12` 依赖（约 2.5GB，含 cudnn 664MB + cublas 410MB）。

### 验证（这才算装了）
```python
import torch
print(torch.__version__)        # 2.4.1+cu121
print(torch.cuda.is_available()) # True
print(torch.cuda.get_device_capability(0))  # (6, 1)  ← Pascal 对上了
x = torch.randn(300,300).cuda(); y = x @ x   # GPU matmul 真的能算
```

### 连带踩的坑：typing_extensions 是 0 字节空文件
装完 torch 报 `ImportError: cannot import name 'ParamSpec' from 'typing_extensions'`。
查出来 `typing_extensions.py` 是 **0 字节**，`pip show` 显示 Version: None ——
这是 **11-04 内存不稳定时期写坏的残留**。
修复：`pip install --force-reinstall "typing_extensions>=4.8"`（`-U` 不够，因为 pip 以为已满足）。

### 通用规则
**装任何带 CUDA 的 Python 包前，先查它默认带哪个 CUDA 版本。**
PyPI 的 torch 越新，默认 CUDA 越新：
- torch 2.4.x / 2.5.x → cu121/cu124（支持 Pascal sm_60/61）
- torch 2.9+ → cu126 是唯一还带 6.x 架构的，cu128 起就只有 sm_70+ 了
- 老显卡（Pascal 及更早）**不要随手装最新版**

## 结论
「AI 便利店」八角色转 3D 的最短路线：**腾讯混元生3D 出模型 → 本地 Blender 绑骨/动作 → 本地 EEVEE 渲**。云卡 0 小时。

## 硬数据（2026-11-18 查证）
- **混元生3D 云 API**：带纹理 20 积分/次、多视图 +10、**绑骨蒙皮 10**、文生动作 10、组件生成 30、智能拓扑 50。积分 0.1 元/个（1000 包），后付 0.12。**首次开通免费 100 积分（控制台手动领，1 年有效）**。
  → 一个带贴图+绑骨的角色 ≈ 40 积分 ≈ **4 元**；8 角色含重试约 **¥60–80**。
- **混元 3D Studio 网页**（3d.hunyuan.tencent.com/studio）：图生多视图+A-pose标准化→几何V2.5(50k/150k/300k)→组件拆分→低模拓扑→UV→纹理→**绑骨蒙皮**→**动作模板库**。实测原神芙宁娜全链 <1 小时（腾讯新闻 2025-09 实测）。
- **开源自建不划算**：Hunyuan3D-2.1 要 10G(形状)/21G(贴图)/29G(全量)，1050Ti 4G 完全跑不了；TripoSG 8G 但**只出白模不带贴图**；TRELLIS 要 16G。AutoDL 4090 卡钱只要 ¥13–15/h×5h，但**装环境 + 调通 10 小时人工**更贵，且贴图更差。

## 二次元的两个崩点（实证）
1. **整身一把梭必翻车**。B站 BV1sBsnz5EuJ（Rodin/Tripo/混元二次元横评）结论：「模型和贴图都不太及格」，必须**手动拆件**（头/身/发/配件分开出），且**挂件/背包/复杂配饰要先删**（「目前可以使用的骨骼没有办法匹配这些结构」）。拆件后混元胜出，进 UE5「精度不错、还原度及格」。
2. **贴图是弱项**。Reddit r/comfyui 2026-05 原话：「geometry from open-source is genuinely great… **Texture baking is the weak spot**」。平涂二次元进 PBR 重建会变塑料 → 贴图回本地用立绘重做更稳。

## 绑骨
- **Mixamo 中国区不可用**（Adobe FAQ 原文：not available for users who have a country code from China），且对「proportions too deformed」直接绑骨失败 → **Q 版大概率不通**，别写进常规流程。许可本身很好（royalty free，可做影片）。
- **混元绑骨**只认标准 A-pose 人形，10 积分/次，先试最便宜。B站 BV1AVwrzkEkQ 实战是「混元导无骨骼 obj → Blender 放大 → 给 Mixamo → UE5」，说明混元绑骨常不理想 + **模型尺寸偏小要放大**。
- **Q 版手工绑最快**：只需 15–20 根骨（无手指/无面部/无物理发），Blender 一个角色 40–60 分钟。
- UniRig 论文宣称覆盖 anime、训练含 VRoid，但**放出的 checkpoint 只在 Articulation-XL2.0 训练，VRoid 主结果未发布**。≥8G 显存。

## 动作
不找动作库（MMD 许可未核实）。Q 版只需要 idle/talk/gesture 三类，用 Blender Python 写三个函数一次生成，八角色共用——和 BPM 运镜层同一思路。

## 渲染实测（本机）
`1050Ti 4G + Blender 4.5.15 EEVEE Next + 1920×1080 + 16 samples + 13 万面` = **1.04 秒/帧**。60 秒片 1440 帧 ≈ 25 分钟，复杂场景 ×2–3 ≈ 50–75 分钟。**EEVEE 是光栅化，本地就能出片，不需要云卡**（云卡只在跑 PyTorch 图生 3D 推理时才必需）。

## 周更取舍
3D 真正的收益不是「更好看」，而是**每集边际成本≈0 + 镜头自由（能转身/走位/多机位）**。前 3 集是纯投入期会拖更，第 5 集后回本。**必须先做 1 个角色 2 天 Pilot，并验一个转身镜头**，否则不值得。

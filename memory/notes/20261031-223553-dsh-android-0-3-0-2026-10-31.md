## 待办（还没升）

升级前要留个心，因为踩过两次同类坑：

1. **`dsh-tools` 必须和运行时版本对齐**。`dsh --version` 显示的版本可能和 npx 实际跑的运行时不是一回事
   （2026-10-30 出现过：CLI 显示 0.2.0-rc.2，实际运行时是 0.2.1-rc.5，导致 tools 插件被禁，
   报 `ReadableStream is already closed`）。详见记忆 `20261030-235236`。
2. 升完先查：`journalctl --user -u dsh --since "-1min" | grep -iE "incompatible|disabling"`，
   输出为空才算插件都正常加载。
3. 升完要确认这几个还在工作：`dsh-core-memory`（记忆）、`dsh-bili-whale`、`dsh-pet`、
   `dsh-free-search`、`local-llm` provider（本地模型那个）。

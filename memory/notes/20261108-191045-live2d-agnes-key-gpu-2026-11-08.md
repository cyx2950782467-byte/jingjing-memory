## Live2D 桌面挂件（2026-11-08 跑通）
电脑 Ubuntu 上做出「鲸鲸站在桌面右下角」的最小版，代码在 `/home/cyx/live2d/desktop/`：
- `main.js`：Electron 透明/置顶/无边框/鼠标穿透窗口，420×720，右下角；另起本地 HTTP 控制口 `127.0.0.1:9878`
- `index.html`：pixi 6.5.10 + pixi-live2d-display 0.4.0（cubism4.min.js）+ live2dcubismcore 5.1.0，加载 `../work/model/deepseek.model3.json`，每 100ms 拉一次嘴型
- 模型和 runtime 都在 `/home/cyx/live2d/work/`（vendor/ 里有全部 js）

**启动命令（参数不能少）**：
```
cd ~/live2d/desktop && DISPLAY=:1 setsid nohup ~/live2d-desktop/node_modules/.bin/electron . \
  --no-sandbox --in-process-gpu --disable-dev-shm-usage >/tmp/jj4.log 2>&1 </dev/null &
```
⚠️ **去掉 `--in-process-gpu --disable-dev-shm-usage` 会崩**：`GPU process launch failed: error_code=1002` → `FATAL: GPU process isn't usable. Goodbye.` → SIGTRAP。这个 SSH 会话里 GPU 子进程起不来，必须同进程跑 GPU。

**说话接口（已验证）**：
- `GET http://127.0.0.1:9878/mouth` → `{"mouth":0}` 闭嘴 / `{"mouth":0.89}` 说话中
- `POST /speak` body `{"durationMs":4000}` → 她张嘴说 4 秒（正弦起伏模拟）

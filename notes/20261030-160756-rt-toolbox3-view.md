## 事实

RT ToolBox3（包括文件名带 **ENG** 的英文版，如 `ToolBox3_Pro_ENG_1.81K`）
**语言可以在软件内直接切换，不需要另装中文版**。

切换位置：**View 菜单**（陈 2026-10-30 实测确认）。

## 我之前的错误判断（要记住别再犯）

2026-10-30 我只看 `Option` 对话框（里面只有 General / Operation Panel /
3D Monitor / Program Editing / MELFA Smart Plus），没看到 Language，
就断言「ENG 版没有中文界面、只能重装中文版」——**这是错的**。
陈在 View 菜单里直接切到了中文。

## 教训

工业软件的语言开关不一定在 Option / Settings 里，也可能在 View 这类
看起来「只管显示」的菜单里。**没翻完所有菜单前，不要下「这个功能不存在」的结论。**
